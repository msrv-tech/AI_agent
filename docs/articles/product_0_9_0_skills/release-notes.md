# 1C AI Agent v0.9.3

Основной фокус релиза - переносимые skills и их первое прикладное применение: создание документов 1С по PDF и изображениям.

## Что нового

- Добавлен реестр skills в 1С: системные и пользовательские сценарии.
- Добавлена форма `ИИА_Skills` с JSON-редактором, генерацией JSON по описанию задачи и тестовым запуском.
- Skills подключаются к обычной форме `ИИ Агент` и попадают в prompt-контекст при совпадении с запросом пользователя.
- В prompt-блок добавлены диагностические поля `target_object_type` и `target_object_name`.
- Для write-сценариев поддерживаются policy, список разрешенных/запрещенных действий и требование подтверждения.
- Улучшен UI формы агента: компактный ввод, пустое состояние, панель хода выполнения, меньше лишних обновлений.
- Добавлен режим `Распознавание документов` и коробочные skills для счета поставщика, УПД/ТОРГ-12, акта услуг и входящей счет-фактуры.
- Добавлены отдельные профили skills для БП и УНФ с проверкой применимости по метаданным конфигурации.
- DSL поддерживает составные workflow через `save_as` и ссылки `$variable` на результаты предыдущих шагов.
- Созданные и измененные объекты выводятся в форме агента кликабельными ссылками.

## Проверка

- Runtime-прогон коробочных skills распознавания в БП и УНФ: `8/8`, PASS.
- Runtime-прогон `dsl_template_json` из карточек skills: `8/8`, PASS.
- Bridge-тесты реестра skills, prompt с вложением и typed plan выполнены на обеих базах.
- UI E2E проверяет полный пользовательский поток и видимые ссылки на созданные объекты.
