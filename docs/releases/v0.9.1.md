# 1C AI Agent v0.9.1

## Главное

- Доведены до рабочего состояния skills: JSON-перенос, запуск skill, генерация JSON по описанию и применение в обычном режиме агента.
- Добавлен и стабилизирован режим распознавания документов через skills для популярных B2B-документов: счет поставщика, УПД/ТОРГ-12, акт услуг, счет-фактура.
- Улучшена универсальность для разных конфигураций 1С: добавлена привязка логики к версии/метаданным конфигурации, снижены ad hoc-зависимости от конкретной базы.
- Улучшены fallback/recovery-сценарии typed plan и DSL: выбор объектов, пустые результаты запросов, предотвращение дублей, нормализация типовых ошибок запросов 1С.
- Перестроен и проверен RAG на тестовых базах BP и UNF.
