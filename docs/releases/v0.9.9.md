# 1C AI Agent v0.9.9

## Главное

- Автотесты и quality gate больше не зависят от COM: прогон идёт через HTTP Codex Test Bridge.
- RunQuery получил универсальный контур `parse → normalize → emit`: виртуальные таблицы, периоды, `ПЕРВЫЕ` на всех ветках `ОБЪЕДИНИТЬ`.
- По умолчанию выборка ограничена (`ПЕРВЫЕ` обычно 100, потолок 500) и усекается при выгрузке. Жёстко запрещены DML, JOIN без `ПО` и `ПО 1=1`.
- Полная выборка доступна только агенту: `RunQuery{query, unlimited:true}` с явным описанием рисков. Пользователя об этом не спрашивают.
- Нормализация `.Обороты` универсальна: голые обороты и сдвинутые даты больше не ломают пустые периоды.
- Добавлена сборка Fresh-редакции (`build_extension_fresh.py`) с ограничением провайдеров и без самообновления.
