# 1C AI Agent v0.9.3

## Главное

- Добавлен и доведен режим распознавания документов через skills для BP и UNF.
- Из коробки проверены skills для счета поставщика, УПД/ТОРГ-12, акта услуг и входящей счет-фактуры.
- Для BP входящая счет-фактура создается через документ-основание, используя стандартное заполнение 1С.
- DSL стал устойчивее для составных workflow: `save_as` сохраняет результат шага в контекст, а `$variable` подставляется в следующих шагах.
- Заполнение документов из OCR пропускает лишние поля, которых нет в целевом объекте метаданных.
- Prompt skills больше не теряет первый skill при длинном `DSL_TEMPLATE_JSON`.
- Quality gate расширен проверкой видимых ссылок на созданные объекты.
