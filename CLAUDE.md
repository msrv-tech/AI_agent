## Кейс 11: Агент-консультант менеджера по продажам

**Задача:** Создать диалогового AI-агента внутри 1С, который по запросу менеджера выдаёт:
1. Актуальные цены по позициям из прайс-листа
2. Историю продаж клиенту за период с расчётом маржинальности
3. Состояние дебиторской задолженности и просрочки

Агент объединяет данные из нескольких источников и отвечает в рамках одного диалога.

**Бонусные сценарии (наши дополнения):**
4. Загрузка прайс-листа из Excel-файла
5. Создание карточки контрагента из файла
6. Формирование сводного отчёта по продажам

## Критерии оценки

| Критерий | Вес |
|----------|-----|
| Корректность данных (цены, суммы, задолженности) | 25% |
| Интеграция нескольких источников данных | 25% |

Бонус: расчёт маржинальности, сравнение с ценой производителя.

## Архитектура расширения (msrv-tech/AI_agent)

### Ключевые модули

| Модуль | Назначение |
|--------|------------|
| ИИА_Сервер | Управление диалогами, логирование, исправление ошибок |
| ИИА_Оркестратор | Серверный цикл: план → DSL → проверка → summary |
| ИИА_DSL | Интерпретатор JSON-команд (Domain Specific Language) |
| ИИА_Метаданные | Работа со структурой конфигурации, поиск объектов |
| ИИА_Промты | Генератор системных инструкций и RAG-контекста |
| ИИА_Провайдеры | Интеграция с LLM (OpenAI-совместимые API) |
| ИИА_RAG_* | RAG-поиск по метаданным конфигурации (TF-IDF) |

### DSL-команды (доступные действия агента)

**Чтение:**
- `GetMetadata` — списки объектов метаданных
- `GetObjectFields` — реквизиты и табличные части объекта
- `CheckObjectExists` — проверка существования объекта
- `RunQuery` — произвольный запрос на языке запросов 1С
- `FindReferenceByName` — поиск ссылки по наименованию
- `SelectObject` — загрузка объекта в контекст

**Запись:**
- `CreateReference` — создание элемента справочника
- `CreateDocument` — создание документа
- `SetField` — установка значения реквизита
- `Write` — запись объекта в базу

**Системные:**
- `ShowInfo` — сообщение пользователю
- `ForEach` — цикл по коллекции
- `SaveToStorage` / `LoadFromStorage` — временное хранилище диалога

### RAG-система

Самописный TF-IDF на BSL, индексирует метаданные конфигурации в регистры сведений 1С.
Не использует внешних векторных баз или эмбеддингов.
Для улучшения качества нужно дополнить `ИИА_RAG_Настройки` синонимами:
- «дебиторка» → «взаиморасчёты»
- «прайс» → «цены номенклатуры»
- «клиент» → «контрагент»
- «долг», «задолженность» → «взаиморасчёты»
- «маржа», «маржинальность» → «себестоимость, цена, прибыль»

### Известные ограничения и патчи

1. **Порт и SSL захардкожены** в `ИИА_Провайдеры.ВыполнитьHTTPИнструмент()` (строка 69): порт 443 + SSL. Для LM Studio (http, порт 1234) нужен патч — выделить порт из URL, сделать SSL опциональным. См. TODO пункт 13.
2. **Серверные уведомления** требуют платформу 8.3.26+ — более ранние версии не поддерживаются.
3. **Безопасный режим** расширения должен быть снят.

## Структура репозитория

```
AI_agent/
├── xml/                    # XML-выгрузка расширения 1С
│   ├── CommonModules/      # Общие модули (BSL-код)
│   ├── CommonForms/        # Формы (агент, настройки, RAG)
│   ├── Catalogs/           # Справочники (диалоги, настройки)
│   ├── InformationRegisters/ # Регистры (чанки, токены, логи)
│   └── Configuration.xml   # Корневой файл конфигурации
├── docs/                   # Документация
├── automation/             # Скрипты автоматизации (Python, тесты)
├── assets/                 # Ресурсы (иконки)
└── CLAUDE.md               # ← этот файл
```

## Что делать при работе с кодом

- BSL-код расширения лежит в `xml/CommonModules/*/Ext/Module.bsl`
- Основная логика: ИИА_Оркестратор, ИИА_DSL, ИИА_Промты, ИИА_Провайдеры
- Промпты для LLM формируются в ИИА_Промты — тюнинг под кейс 11 делать там
- RAG-настройки (синонимы, стоп-слова) в ИИА_RAG_Настройки
- Тесты: `automation/run_tests.py` или модуль ИИА_Тесты в 1С
